gmail-mcp Privacy Policy

Last updated: November 8, 2026. Back to the gmail-mcp home page.

What this app is

gmail-mcp is a personal tool used only by its owner, to work with the owner's own Gmail account from the owner's own computer. It has no other users.

Google user data the app accesses

When the owner signs in with Google, the app asks for these permissions:

  • gmail.modify: read, search, label, draft and send the owner's email, and download attachments.
  • gmail.settings.basic: manage the owner's Gmail filters and labels.

How the data is used

Data is read only to carry out a request the owner makes, such as searching mail, reading a message or saving an attachment. It is not used for advertising, profiling, analytics or machine-learning training by this app.

How the data is stored

The app keeps no copy of email on any server. The only thing it stores is the Google sign-in token, in a file on the owner's own computer. Mail content that the owner asks the assistant to read is handled in the owner's own AI assistant session, under that assistant's own terms.

Sharing

The app does not sell, transfer or share Google user data with anyone. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting access

The owner can revoke the app's access at any time at myaccount.google.com/permissions, and can delete the stored token file from their computer.
