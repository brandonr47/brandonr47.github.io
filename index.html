gmail-mcp

gmail-mcp is a small personal tool that lets one person's own AI assistant work with that person's own Gmail account from their own computer.

What it does

  • Searches and reads the owner's email, so the assistant can answer questions about it.
  • Downloads attachments the owner asks for.
  • Creates drafts and labels, and sends mail only when the owner asks for it.

Who it is for

It is used by its owner only. It is not offered to the public, has no other users, and does not run on any server. The sign-in token is stored on the owner's own computer.

Privacy

Read the Privacy Policy to see how Google user data is accessed, used, stored and shared (it is not shared).
